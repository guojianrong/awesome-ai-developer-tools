# Contributing

Thanks for helping maintain Awesome AI & Developer Tools.

## What belongs here?

This repository focuses on tools that are useful to:

- software developers
- engineering teams
- technical founders
- DevOps and platform engineers
- AI application builders
- API and infrastructure developers

The list includes both AI-native tools and important developer infrastructure that is directly relevant to modern AI/software development workflows.

## Before submitting

Please check that:

1. The tool is not already listed.
2. The official website or public project page is available.
3. The description is factual and concise.
4. The suggested category is appropriate.
5. The submission does not rely on affiliate links or promotional copy.

## Pull request format

Please include:

- Tool name
- Official URL
- Suggested category
- One-sentence factual description
- A short reason the tool is useful to developers

## Maintenance

Tools, pricing, features, availability, and URLs can change. If you notice outdated information, please open an issue or pull request with the relevant correction.

Please avoid unsupported claims such as “best”, “#1”, “most popular”, or “fastest” unless there is a clear, verifiable source and the claim is genuinely necessary.
