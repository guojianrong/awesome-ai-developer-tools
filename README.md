## How the categories work

The source database contains tool names, taglines, descriptions, official website URLs, and other metadata, but it does not contain a dedicated category table in the supplied export.
The categories in this README are therefore **editorial groupings inferred from the supplied tool data**. They are intended to make the list easier for developers to browse and are not claims that the original database assigned these exact categories.

Tool descriptions above use the supplied dataset's taglines rather than adding unsupported product claims.
